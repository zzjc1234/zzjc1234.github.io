# Zhaojiacheng Zhou

Personal research homepage: https://zzjc1234.github.io/

Static HTML and CSS, published from `main` by GitHub Pages. No build or runtime dependencies.

## Edit and preview

- Content: `index.html`
- Theme and responsive layout: `assets/home.css`
- Portrait: `assets/portrait.jpg`
- Run `python3 -m http.server 8000` and open http://localhost:8000.
- Run `python3 checks.py` before publishing.

The previous Hexo archive URLs are preserved. The homepage uses its own stylesheet so those pages remain intact.

## Design references

Original static implementation, with the [Tokyo Night](https://github.com/folke/tokyonight.nvim) palette and editorial/terminal inspiration from [MultiTerm](https://github.com/stelcodes/multiterm-astro) and [AstroPaper](https://github.com/satnaing/astro-paper). No template source code was copied.

Research and project descriptions are based on the September 2026 Chinese résumé. Prefer official conference and publisher records over arXiv for publication metadata:

- E-mem: the eleven-author list and order follow the [ICML 2026 page](https://icml.cc/virtual/2026/poster/65274) and [OpenReview record](https://openreview.net/forum?id=FAjA0snAYq). Code links to the repository listed by ICML.
- MAS-Shield: the [OpenReview link](https://openreview.net/forum?id=8mu5EeBWwm) was supplied by the author. The final author and contribution details still need verification against the official PDF; automated access was blocked. The existing author-confirmed co-first status is retained.
- Computer Networks: the author list and 2025 publication year follow the [publisher record](https://doi.org/10.1016/j.comnet.2025.111458).
- PROTEUS: keep the author-confirmed NeurIPS 2026 title, six-author list, and Poster status. The author requested no further changes for now; the linked arXiv preprint has older metadata.

The résumé PDF is not published; the homepage contains the relevant academic information and email contact.
